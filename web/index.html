Your data stays yours.

ZYRON stores workspace data locally in your browser or app. Files are opened only when you choose them.

LOCAL STORAGE ● ACTIVE

ZYRON's labs work on local sample data and files you choose. The optional Memory Lab (rooted Android only, explicit root approval) can read and edit the memory of an app you select: use it only on offline or single-player software you own or are authorized to test, never on online games or other people's accounts. ZYRON does not bypass anti-cheat or security controls, and system or protected apps cannot be attached.

SCRIPT

JavaScript ile otomasyon

Game Guardian'ın Lua scriptlerine benzer gg API'si (JavaScript, await ile). Yalnızca kendi yazdığın veya güvendiğin scriptleri çalıştır: script bağlı uygulamanın belleğine yazabilir.

Konsol hazır.
gg API başvurusu
Tüm gg.* çağrıları Promise döner: await kullan. print(...) konsola yazar.

Sabitler
  gg.TYPE_AUTO TYPE_BYTE TYPE_WORD TYPE_DWORD TYPE_QWORD TYPE_FLOAT TYPE_DOUBLE TYPE_XOR
  gg.REGION_ANONYMOUS C_HEAP C_ALLOC C_DATA C_BSS JAVA_HEAP JAVA STACK ASHMEM VIDEO CODE_APP CODE_SYS OTHER (| ile birleştir)
  gg.SIGN_EQUAL NOT_EQUAL GREATER LESS FUZZY_EQUAL FUZZY_NOT_EQUAL FUZZY_GREATER FUZZY_LESS

Arama
  gg.setRanges(maske) / gg.getRanges()
  gg.searchNumber(metin, tür=AUTO, _, işaret=EQUAL)   metin: "100", "10~20", "100;200;300::512" (grup, harf eki: D=dword F=float E=double Q=qword W=word B=byte)
  gg.refineNumber(metin, tür, _, işaret)               işaret: EQUAL, NOT_EQUAL, GREATER, LESS, FUZZY_*
  gg.searchFuzzy(fark=0, işaret=FUZZY_EQUAL, tür=AUTO)
  gg.searchPointer(azamiOfset)                         (ilk sonuç için)
  gg.getResultsCount() / gg.getResults(adet, atla)     [{address,value,flags}]
  gg.clearResults()

Düzenleme
  gg.editAll(değer, tür)  gg.getValues(liste)  gg.setValues([{address,flags,value,freeze:true,freezeMode:'inc'|'dec'}])
  gg.addListItems(liste)  gg.getListItems()  gg.removeListItems(liste)  gg.clearList()

Süreç ve diğer
  gg.getTargetInfo()  gg.getTargetPackage()  gg.processPause()  gg.processResume()
  gg.getRangesList()  gg.dumpMemory(başlangıç, bitiş)
  gg.sleep(ms)  gg.toast(m)  gg.alert(m)  gg.prompt(m, varsayılan)  gg.choice(liste, _, m)  gg.copyText(m)

Farklar: Lua yerine JavaScript. Bellek aralığı (from/to) ve limit parametreleri yok sayılır. ASM/disassembler ve hız hilesi desteklenmez.
